# BranchDeck 使用指南

[English overview](../README.md) · [中文介绍](../README.zh-CN.md)

本指南介绍工作区发现、命令匹配、终端行为及配置细节。

## 使用

在 macOS 上构建并打开应用：

```sh
npm ci
npm run pack
open release/mac-arm64/BranchDeck.app
```

以上路径适用于 Apple Silicon；Intel Mac 的输出目录为 `release/mac`。本地构建包未签名、公证。

界面分成三列，各自滚动：

1. **工作区**：自动发现仓库、主工作区与 worktree，支持搜索和来源筛选。
2. **工具**：「快捷命令 / 文件」切换。快捷命令可以执行、填入后编辑，或调整配置。文件可以在右侧预览；目录悬停按钮或右键菜单可在该目录新建终端。整列可以收起。
3. **终端与查看**：进入工作区自动打开一个登录交互式 zsh，支持自由输入、别名、函数、Tab 补全、上下键历史、Ctrl+C、颜色及全屏终端程序。终端有独立标签，点击加号新建；文件预览不打断终端。

左栏悬停目录或仓库分组会显示移除按钮：可移除单个工作区，或整个分组（包括之后发现的同仓库 worktree）。支持立即撤销，也可从左栏底部「已移除目录」恢复；重扫和重启不会自动加回。项目文件、命令配置和正在运行的终端保留，恢复后可返回原会话。手动重新添加具体目录也会解除该目录及所属分组的移除记录。

两条列间分隔线可左右拖动调整宽度，双击恢复默认；列宽自动保存。分隔线聚焦后也可用左右方向键调整。

命令左侧的六点手柄支持拖动排序，搜索后的列表也能调整；顺序按工作区保存，重启不变。手柄聚焦后用 `Option + ↑/↓` 移动。悬停命令显示移除按钮；移除后可以立即撤销，或从列表底部「已移除」恢复。移除只影响快捷列表，不删除项目文件、不结束正在运行的终端；扫描不会重新加入它。重新手动保存或导入同一命令可主动加入。

终端标签可以左右拖动排序，点击 × 关闭；标签顺序仅在本次界面会话内保留。

普通快捷命令优先使用当前空闲 Shell；忙碌、有未提交输入或属于另一工作区时新开终端。命令的执行目录仍以配置为准，必要时先切换目录；环境变量只对这次快捷命令生效。手动输入遵循正常 Shell 行为。

服务使用独立标签，并保留原有端口检查、自定义关闭和进程保护；重复执行同一运行中的服务会定位到已有标签。服务停止或失败后，该标签会回到可输入的 Shell。普通命令结束后也会回到提示符；Ctrl+C 中断程序，不关闭 Shell。

应用运行期间，切换工作区、文件视图或隐藏窗口均保留各终端的进程、目录、输入与输出。最多保留 32 个标签。完全退出应用会关闭会话；重启后不会恢复旧进程或自动重放命令。

快捷键：`⌘T` 新终端、`⌘W` 关闭当前终端、`⌘B` 收起/展开工具。Ctrl 系列保留给 Shell。关闭忙碌终端或有未提交输入的标签时，由主进程实时检查后要求确认。

文本预览限制 1 MB，二进制文件暂不支持；目录与文件访问校验真实路径，禁止符号链接越出工作区。

设置按钮里可调整启动命令、执行目录。高级设置默认折叠，包含运行类型、环境变量、就绪端口、关闭信号、等待时间和关闭前执行的命令。标签仅用于展示，环境由实际命令和变量决定。

## 自动识别终端历史

首次打开一个工作区时，按频次自动整理最多 8 条匹配的历史命令，补充少量项目启动项及 Git 状态/差异命令；保留全部已有自定义配置。历史次数与子目录直接显示在命令下方，不必手动导入或填写路径。

之后每 5 分钟扫描一次，新命令进入折叠的「发现 N 条可添加命令」，点击加号加入、叉号忽略；选择会保存，重启和重扫不会重复建议。既有常用列表不会因历史轮换而消失，也不会自动重排。定时器仅在应用运行时生效，关闭窗口留在菜单栏仍继续，完全退出后停止。
匹配方式：

- 命令里已明确指定当前工作区目录，直接关联。
- 未记录目录的 npm/pnpm/yarn/bun 命令，与工作区内 `package.json` 的脚本名匹配，只有唯一匹配才自动关联。
- Maven、Gradle、Make、Docker Compose 与相对脚本路径，按工作区内的唯一配置文件/目标/脚本文件匹配；相对 cd 必须匹配实际目录与项目脚本。
- 多个子项目都有同名脚本、带复杂范围选项或无法匹配的命令，可通过搜索旁的历史图标补充关联。
- 匹配表示命令适用于当前项目的建议，并不表示能够还原历史的实际工作目录。不会根据相邻 cd 猜测，不进入依赖目录或嵌套 Git 检出。
- 相同命令合并到已有按钮，保留已保存的端口、环境变量和名称。仅自动展示，不自动执行；首次点击执行时按原有流程保存配置。对疑似会修改项目的历史命令保留执行确认。

中间列的历史入口仍支持搜索、筛选、选择目录和批量保存，供未能自动匹配的命令补充关联。自动匹配最多处理频次最高的 2,000 条候选，每个工作区最多匹配 24 个新增历史候选；项目文件扫描最多 200 个目录、深度 3。

- 来源：本机 `.zsh_history`、`.bash_history`、最近 12 个 `.zsh_sessions/*.history`，导出的 HISTFILE，以及 Shell 配置中可静态解析的 HISTFILE 字面值；也可手动选择历史文件。
- 支持 zsh 扩展时间戳、bash 时间戳、常见开发命令（npm/pnpm/yarn/bun、Maven/Gradle/Make、部分 Git 和 Docker Compose、脚本启动）。复杂 Shell 表达式及疑似包含凭据或明显高风险操作的命令会跳过，无法保证识别任意形式的敏感内容。
- 自动区分常驻服务与一次性命令，按历史记录频次排序。相同时间戳的会话副本不重复计数；没有时间戳的副本取单文件最大频次。
- 手动补充关联页：普通 history 不记录执行目录。仅从同一条命令的 `cd /绝对路径 && ...` 或 `git -C /绝对路径 ...` 关联目录，绝不把相邻 `cd` 当作可靠依据。其余候选默认建议当前工作区，可在导入前更改；相对 cd 保留在命令中。
- 扫描不执行命令、不 source Shell 配置、不上传历史、不持久化完整历史；初始化或接受的常用命令及忽略选择会保存到本地。候选最多展示 300 条，每次最多导入 100 条；每文件最多读取最近 4 MB，总量最多 16 MB、最多 20 个文件。
- 只读取已落盘的历史；尚未保存的当前终端记录可能缺失。暂不支持 fish、iTerm 专有数据库或 Shell 别名展开，未支持的命令可继续手动添加。

## 自动发现范围

仅在本地读取项目元数据，不读取对话正文，不修改 Codex / Claude Code 的配置或数据库。

- Codex：保存的工作区、local-projects、目录提示、SQLite 项目目录 / 未归档会话 cwd，以及 `.codex/worktrees`。
- Claude Code：`.claude.json` 的 projects 路径、已有 sessions-index 的 projectPath、项目内 `.claude/worktrees`。
- Git：只读 `worktree list`、仓库根目录、当前分支与提交；同一路径通过 realpath 去重，多来源显示在同一项。
- 通用目录：读取 `~/code`、`~/Projects`、`~/Developer`、`~/Documents/code`、`~/Documents/Projects`（大小写均识别）的两层子目录，最多检查 300 个目录，以项目配置或 Git 标记确认。
- 终端路径：从明确的 `cd /绝对路径` 或 `git -C` 寻找现存项目；不据此给后面的命令猜测执行目录。
- 豆包等其它工具没有专有元数据适配器；其项目位于上述路径、终端历史路径或手动添加的目录时，可通过通用发现纳入。
- 扫描每 5 分钟刷新；手动刷新立即重新扫描。仅处理实际存在的本地目录，不扫描整块硬盘、不使用项目会话正文推测路径。元数据来源升级导致部分索引不可用时可能需要手动添加目录。

工作区发现最多先检查 350 个候选目录，目录树单层最多展示 150 项。启动项在工作区内最多扫描 200 个目录、深度 3，排除 node_modules、Git 内部目录、构建产物、嵌套独立检出和符号链接目录。多包项目显示相对执行目录。

启动识别支持：

- `package.json` 中常用 dev / start / serve / test / build 脚本；从 packageManager 或锁文件选择 pnpm、npm、yarn、bun。
- Makefile 的常见 dev / start / run / serve / test / build 目标。
- 声明 Spring Boot Maven 插件的 pom.xml（可能仍需自定义 JDK、profile 或业务环境参数）。

扫描本身只生成建议，不执行项目命令或安装工具。进入工作区会启动交互 Shell，按正常终端方式加载用户启动配置。首次点击运行才保存该启动项；后续自定义优先，旧版本的配置与运行记录继续保留。无法识别的项目可手动添加命令。

## 命令和关闭方式

Git 查看命令可以与开发服务同时运行。「快进拉取」会展示目录和命令并要求确认，只运行 `git pull --ff-only`；不自动切分支、合并、提交或推送。远端访问失败会显示日志。命令运行于真实 PTY，支持交互输入。内置 Git 快捷命令仍禁止终端凭据提示；需要先配置认证。

普通终端直接运行 `/bin/zsh -il`，通过本机独立的启动包装文件加载用户 `.zshenv`、`.zprofile`、`.zshrc`、`.zlogin` 并接入提示符状态；不修改用户原配置。当前支持 zsh，暂未接入 bash/fish 的交互状态识别。

服务通过 `/bin/zsh -c` 托管运行；普通快捷命令进入交互 Shell，继承其环境并应用配置变量。使用前台服务，避免 nohup、setsid 或 daemon 模式。环境变量保存在本机明文配置，请勿存入长期密钥；日志仅尽力遮蔽配置值，不保证所有输出均能脱敏。

默认停止向本次进程组发送 SIGTERM，可以改成 Ctrl+C / SIGINT。可先执行自定义关闭命令（最多 5 秒），随后正常结束进程组。超出配置等待时间后结束组内进程；主动脱离进程组的 daemon 不受管理。程序不会根据名称或端口杀掉外部进程。

同目录的常驻服务互斥，一次性任务可并行。可选就绪端口必须由本次进程组监听才标记为就绪；未设端口只表示进程运行，不代表业务已验证。

如需与外部服务管理器协作，可在启动应用的环境中设置 `BRANCHDECK_EXTERNAL_RUNTIME_DIR` 为描述文件根目录的绝对路径。应用检查该目录下的 `*/runtime.json`，其中 `repoRoot` 为仓库根目录，`ownerPid` 为进程号；匹配当前仓库且进程仍存活时阻止重复启动，不停止外部进程。默认不读取任何项目专属运行目录；端口占用检查始终保留。

关闭窗口后继续在菜单栏运行。退出时关闭本应用的终端和托管服务；关闭 Shell 会结束其 PTY 内的任务，不处理主动脱离终端的 daemon。服务运行日志仍保存，普通 Shell 的屏幕输出仅在本次应用运行期间保留，不保存完整终端录制。

## 数据和开发

数据保存在 `~/Library/Application Support/BranchDeck/`，包含 configs.json、command-catalog.json（常用列表、排序、忽略及移除项）、scan-roots.json、removed-workspaces.json（移除目录与分组）、history.json 和独立运行日志。可从应用设置打开。配置文件原子写入、权限 0600；日志约 10 MB 轮换一次并保留 `.1`。旧运行日志可在 Finder 清理。

```sh
npm ci
npm run dev
npm test
npm run build
node scripts/terminal-manager-smoke.mjs
node scripts/organize-smoke.mjs
node scripts/workspace-remove-smoke.mjs
node scripts/history-smoke.mjs
node scripts/suggestions-smoke.mjs
npm run pack
node scripts/terminal-manager-smoke.mjs "$PWD/release/mac-arm64/BranchDeck.app/Contents/MacOS/BranchDeck"
node scripts/lifecycle-smoke.mjs
```

要求 macOS、Node.js 22.12+、npm、git、zsh、ps、lsof、sqlite3。测试使用临时 Git 仓库和测试服务，不对真实项目执行 Git 写操作或启停服务。目前不包含 Windows、远程环境或多服务依赖编排。

## 仓库内容与隐私

仓库仅包含源码、依赖锁文件、应用图标、说明文档及使用临时数据的测试。首次启动不预置个人项目或命令。工作区路径、Shell 历史、命令配置、环境变量和运行日志由应用在本机读取或生成，不作为仓库内容分发。

依赖、构建目录、各版本安装包、测试截图、本地验收记录、环境文件及凭据文件已加入 `.gitignore`。提交前仍应检查 `git diff --cached`，避免将个人路径、内网地址或密钥写进源码和示例。测试生成的截图仅供本地验收。
