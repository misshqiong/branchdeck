# 发布隐私检查

- Git 提交与标签使用项目署名和非个人邮箱。
- 不提交真实姓名、邮箱、个人目录绝对路径、签名团队 ID、证书指纹或其他项目名称。示例使用相对路径、环境变量或明确的测试占位符。
- 签名身份和公证凭据由本机环境变量或钥匙串提供。私钥、描述文件及本地构建记录不得提交。
- 打包前通过 `scripts/sanitize-package.cjs` 移除 node-pty 原生模块的调试符号，并检查原生模块与应用归档是否仍包含当前用户的个人目录路径。检查失败则停止发布。
- 不自动生成包含仓库所有者信息的更新配置；重新接入更新服务前必须明确其信息披露范围。
- 产物修改必须在签名前进行；修改已经签名的产物会使签名或公证失效。
- Apple Developer ID 签名本身包含证书主体身份。个人证书签名的应用不能承诺匿名发布；发布前必须审查证书身份，不得仅删除文档中的姓名便认为已清除身份信息。

历史 Release 已因隐私问题撤下。旧包不得重新发布。远端引用修改和 Release 删除不能收回已下载的副本，也不能保证托管平台内部缓存立即清除。
