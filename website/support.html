BRANCHDECK

Getting started

Install on your Mac

  1. Download the DMG for Apple Silicon.
  2. Open it and drag BranchDeck into Applications.
  3. Launch BranchDeck from Applications.
  4. Select a discovered workspace or use Add directory to choose a project folder.

The current 0.11.0 download supports English and Simplified Chinese.

Use your existing tools

BranchDeck uses interactive zsh and your shell configuration. Your development runtimes, Git, and project dependencies must already be installed. It does not bundle Node.js for your project commands.

Keep sessions running

Switching workspaces and hiding the window keep terminals alive while the app runs. Fully quitting closes terminals and stops managed services. Sessions are not restored after a restart.

Check a download

Compare the downloaded file with the published SHA-256 checksums. In Terminal, use shasum -a 256 followed by the downloaded file path. If macOS reports a damaged or unverified download, download it again and verify the checksum. Do not disable Gatekeeper.

If a command does not work

Check that the same command works in Terminal from the same project directory. Review the shortcut’s working directory and environment. Use a new terminal tab if the existing one is busy or contains unfinished input.

Before sharing a bug report

Include the app version, macOS version, and steps to reproduce. Remove usernames, personal paths, environment variables, tokens, and private command output. Report bugs or suggest improvements through GitHub Issues. Issues are public, so review your report for personal information before posting.

Browse Claude chat files

Choose “Scan Claude chat cache” in the sidebar. After scanning, click a category to open its files, or choose “Browse all files”. Save locations and scan details are expandable. The scan only recovers content retained on this Mac; some indexed chats have no message bodies. Repeated scans create separate snapshots.

Choose a language

Open Settings to switch between English and Simplified Chinese.
