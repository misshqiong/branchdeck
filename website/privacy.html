BRANCHDECK

Local data & privacy

BranchDeck is a desktop workspace tool. This page describes the current direct-download build and this website.

What the app reads

Workspace discovery reads local project metadata, Git worktree information, configured development folders, and relevant shell history. It does not read coding conversation bodies. Discovering or importing a command does not execute it.

What stays on your Mac

Workspace settings, saved commands, preferences, and service logs are stored locally, normally under ~/Library/Application Support/BranchDeck/. BranchDeck does not upload your workspace catalog or shell history and does not include analytics in the current build.

Saved environment variables are stored as plain text. Log redaction is best effort. Avoid putting secrets in saved commands, screenshots, or support reports.

Commands have their own behavior

Terminals use your login shell configuration. Commands you execute can access files and contact network services according to your environment and the command. BranchDeck does not isolate those commands from your Mac.

This website

This static site does not use advertising, analytics scripts, third-party fonts, or account cookies. The web server may process ordinary request information, including IP address and browser information, to deliver pages and downloads. Downloads are hosted on the same site.

Removing local data

Quit BranchDeck before removing its data directory. Back up any saved commands you need first. Deleting app data does not delete your project folders. Folder deletion inside the app is a separate, confirmed action.

Release signatures

macOS installers carry an Apple Developer ID signature. The certificate identifies the signing developer and can be inspected with macOS tools. Notarization checks the submitted build; it is not an App Store listing.
